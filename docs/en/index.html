No commands needed: say one sentence to your AI agent, or download and double-click

Delete 360 software, starting with a check of your PC

This is an open-source AI agent skill. Tell an agent that can run commands on your PC "check this PC for 360 software", and it checks first, then tells you in plain words whether each product (360 Total Security, 360 browsers, 360 Software Manager, the Duohui screen saver and more) “can be deleted” or “won't be deleted”. It deletes only after you name the numbers and confirm. If your agent cannot run local commands, download and extract the whole ZIP, then double-click Start-Check: the window says the same things and opens with nothing ticked.

Use an AI agent (recommended)

Say one sentence, and the agent tells you what can go

The agent follows the skill's SKILL.md to run the check, then uses the bundled Show-360Summary.ps1 to turn the result into plain words. It may suggest, but only you say whether to delete and which items.

  1. 1

    Give the agent this skill

    Codex users copy the complete repository to %USERPROFILE%\.codex\skills\windows-360-cleaner. For other agents that can run local commands, send them the repository address and ask them to read SKILL.md completely first. If you are not sure, ask first: “Can you run PowerShell on this Windows PC?”

  2. 2

    Say one sentence

    “Check this PC for 360 software, tell me in plain words what you suggest deleting and what won't be deleted, and delete only what I confirm.” Checking never deletes anything.

  3. 3

    It numbers the products and says what can go

    For example: “1. 360 Secure Browser - 1 can be deleted, 1 not. Do you still use 360 Secure Browser? If not, I suggest deleting it. 2. 360 Huabao / Duohui screen saver - Can be deleted (3), I suggest deleting it. 3. 360 temporary files - Won't delete: not sure it belongs to 360. Which ones should be deleted? Just reply with the numbers.” It never suggests deleting, or works around, anything marked “won't delete”.

  4. 4

    It deletes only after you confirm

    Reply with numbers, for example “delete 2”. It first shows you the confirmation text: what is deleted, what deleting does, what you did not select (this tool does not delete it), and that deleted items cannot be recovered and do not go to the Recycle Bin; when an uninstaller that came with 360 is included, it also warns that the uninstaller may remove unselected parts of the same product. It starts only after your explicit “yes, delete”; click “Yes” when Windows asks for permission. Numbers you do not name are kept, and “delete everything” only covers items that can be deleted.

  5. 5

    Restart yourself, then let it check

    It tells you honestly what was deleted, what is left, and whether to restart; “not deleted” and “not sure” are never called finished. It never restarts your PC: save your work, restart yourself, then tell it “it has restarted”. In a new conversation, say “check the last deletion”.

Agents that cannot run local commands, such as Doubao on the web, cannot reach your PC: ask them to guide you to the Start-Check window below, and they can help you understand its text. See the Doubao guide (Chinese, with an English prompt); the full example conversation and prompts are in the README.

If your agent cannot run local commands

Double-click Start-Check: six steps, and you decide at every one

  1. 1

    Download and extract everything

    Click “Download ZIP” above. Right-click the downloaded ZIP, choose “Extract All”, then open the extracted folder. Do not run anything from inside the ZIP, and avoid modified copies from unknown sites.

  2. 2

    Double-click Start-Check

    Double-click Start-Check.cmd (开始检查.cmd is an identical copy with a Chinese name). Opening it only checks the PC and deletes nothing. The window shows only the current step and the elapsed time; it usually takes a minute or two. “Stop checking” stops it, and that result is not used.

  3. 3

    Read the results and tick for yourself

    Results are grouped by product and nothing is ticked. The “Delete?” column has only two kinds of answers: “Can be deleted” is your decision; rows that say “Won't delete: reason” cannot be ticked. Click any row to see below what it is and what deleting it does. “Select all deletable” ticks only items that can be deleted and, for safety, only ever selects less, never more. If you do not want to delete anything, just click “Close”.

  4. 4

    Confirm what will be deleted

    Click “Delete selected...”. If the selection needs changes (for example more than 64 items), the tool explains how to fix it first, and nothing has been deleted yet. The “Delete these items?” dialog states that deleted items cannot be recovered and do not go to the Recycle Bin, and that what you did not select is kept (if you ticked an uninstaller that came with 360, it warns separately that it may remove unticked parts of the same product). Close the 360 programs and back up bookmarks you need, then click the red “Delete” and click “Yes” when Windows asks for permission. When in doubt, click “Cancel”, the default button.

  5. 5

    Read the result and restart yourself

    Once deleting starts it cannot be stopped, so let it finish. The result page gives a large headline such as “Deletion complete”, “One more step: restart the PC”, “Some items were not deleted”, or “Not sure everything was deleted”, and says what to do next; not deleted, uncertain, and restart-needed results never look like success. The tool never restarts the PC; save your work and restart it yourself.

  6. 6

    Check the last deletion after restarting

    Double-click Start-Check again and, under “Last deletion”, click “Check the last deletion”. Checking only reads information and never deletes anything. Items you kept are listed under “Kept by you” and do not count as a failed deletion.

Read the “Delete?” answer

Every item has one of two answers: can be deleted, or won't delete

The window and the agent use the same words. The answer comes from local locations, installed-program records, timer tasks, background services, digital signatures, or file contents. A name that contains “360” is not enough.

Can be deleted
Something 360 left behind that can be deleted. Tick it in the window, or name its product's number in a conversation (a number covers the items of that product that can be deleted, only ever fewer for safety, and the confirmation text lists them; to delete only some of them, use the Start-Check window). The window does not decide for you; an agent may say “I suggest deleting it” and asks first about software you may still use. Only what you confirm is deleted, and everything else is kept.
Won't delete: reason
For example, the name or location looks like 360 but it is not certain that it belongs to 360. These items only show the reason, cannot be ticked, and an agent never suggests deleting them or works around them: Won't delete: not sure it belongs to 360 · Won't delete: bookmarks and history · Won't delete: in another Windows installation · Won't delete: system driver · Won't delete: this is other software · Won't delete: details incomplete · Won't delete: uninstall it normally first

Never deleted

Normal files and personal data are not targets because of a name

Ordinary numeric files

Photos, game assets, models, hashes, and other content whose only signal is “360” in a name are not evidence of 360 software.

Windows and drivers

Built-in screen savers, GPU and network drivers, Driver Genius, and other normal software are not removed by keyword. 360 system drivers are only listed and never deleted.

Browser personal data

A browser's program files and its personal data are separate items. Bookmarks, history, and other personal data show “Won't delete: bookmarks and history”, cannot be ticked in the Start-Check window, and are never included by an agent.

Other Windows installations

A Windows installation on another drive is only checked and listed. This project provides no cross-system deletion.

Privacy and help

Results stay on your PC; check the text before asking for help

This introduction contains no analytics, advertising, or tracking scripts. Checking, deleting, and the check after a restart run on your PC, and the tool never uploads anything. Record files are JSON files saved to your Desktop by default, named like 360-cleanup-scan-….json; you do not need to open them, because the window and the agent explain them in plain words.

To ask for help, click “Get help” on a result page of the window. It creates separate problem information with your user name, computer name, SIDs, e-mail addresses, and private paths hidden as far as possible, though something may be missed. You can edit it; check every line before sharing. The original records are not changed, and the text can never be used to delete anything. “Open the help web page” only opens a fixed help page in your browser; it does not send anything for you.

Frequently asked questions

What to know before you begin

Is this a one-click cleaner?

No. It checks the PC, tells you for each item whether it can be deleted, and deletes only what you confirm yourself. The window opens with nothing ticked, and “Select all deletable” ticks items only when you click it; an agent may suggest, but deletes only the numbers you name.

Do I need an AI agent?

Not necessarily. An agent that can run commands on your PC (for example Codex) is recommended: it follows SKILL.md, checks, and tells you in plain words what can be deleted. If your agent cannot reach your PC (for example Doubao on the web), or you do not use one, double-click Start-Check; it says exactly the same things. See the Doubao guide (Chinese, with an English prompt).

The agent says “I suggest deleting it”. Do I have to?

No. A suggestion is only a suggestion: only the numbers you name are deleted, and anything you do not name is kept. Before deleting, the agent must show you the confirmation text and wait for your explicit “yes, delete”. If it says it is done but cannot show a real check result, do not believe it.

Do I need to install anything or be an administrator?

Nothing to install: Windows 10/11 already includes Windows PowerShell 5.1. Checking does not need administrator rights; Windows asks for permission only when you confirm a deletion.

Which software can it check?

360 Total Security / 360 Antivirus, 360 Secure Browser and 360 Speed Browser, 360 Software Manager, 360 Huabao / the Duohui screen saver, 360 program files inside winToolBox, plus related programs that run at startup, background services, and tasks that run on a timer. It does not cover every version; see the detection catalog for the maintained scope.

I only deleted some items. Will the next check report a failure?

No. “Check the last deletion” separates “Not deleted”, “Could not be confirmed or not fully checked”, “Newly found or changed”, “Kept by you, but gone”, “Kept by you”, and “Deleted”. Items you kept that are still there are normal, not failures. Checking never deletes anything; to handle new items, check the PC again and decide again.

What if I clicked “No” when Windows asked for permission, or the result says “Not sure everything was deleted”?

If you click “No”, nothing is deleted, and the window's result page says “Nothing was deleted”. “Not sure everything was deleted” means the outcome could not be confirmed, so do not treat it as done: save your work, restart yourself, and check again (click “Check the last deletion” in the window, or tell the agent “it has restarted”). If it still cannot be confirmed, click “Get help”.

Does it restart the PC, run at startup, or upload data?

No. Neither the tool nor the agent restarts the PC for you, and the tool never runs at startup, never stays in the background, and never uploads anything. When a restart is needed, you are only told to do it yourself.

How do I ask for help without exposing private data?

Click “Get help”, check every line, copy or save it, and paste it into a GitHub Issue. Do not post the original record files publicly, and do not attach screenshots you have not checked.
