不用懂命令：对 AI Agent 说一句话，或者下载后双击

删除 360 软件，先从检查电脑开始

这是一个开源的 AI Agent 技能包。对能在电脑上运行命令的 Agent 说“帮我检查这台电脑上的 360 软件”，它会先检查，再用大白话告诉你 360 安全卫士、360 浏览器、软件管家、多绘屏保等每个软件“可以删除”还是“不删除”；你说出编号并确认后，它才会删除。Agent 不能运行本机命令时，下载并全部解压后双击“开始检查”，窗口里说的是同样的话，打开时一个都不勾选。

用 AI Agent（推荐）

说一句话，Agent 告诉你删不删

Agent 按技能里的 SKILL.md 运行检查，再用项目自带的 Show-360Summary.ps1 把结果变成大白话。它可以给建议，但删不删、删哪几个，只能由你来说。

  1. 1

    让 Agent 用上这个技能

    Codex 用户把整个仓库复制到 %USERPROFILE%\.codex\skills\windows-360-cleaner。其他能运行本机命令的 Agent，把仓库地址发给它，让它先完整读取 SKILL.md。不确定的话，先问它：“你能在这台 Windows 电脑上运行 PowerShell 吗？”

  2. 2

    对它说一句话

    “帮我检查这台电脑上的 360 软件，用大白话告诉我哪些建议删除、哪些不删除，只删除我确认的。”检查不会删除任何东西。

  3. 3

    它按编号告诉你删不删

    例如：“1. 360 安全浏览器 —— 可以删除（1 项），1 项不删除。你还在用 360 安全浏览器吗？不用的话建议删除。2. 360 画报 / 多绘屏保 —— 可以删除（3 项），建议删除。3. 360 临时文件 —— 不删除：不能确定是 360 的。要删除哪几个？回复编号就行。”写着“不删除”的，它不会建议删，也不会想办法绕过。

  4. 4

    你确认后才删除

    回复编号，例如“删除 2”。它先给你看确认内容：要删除的、删除后会怎样、你没选的哪些本工具不会删、删除后不能恢复也不会放进回收站；选了 360 自带的卸载程序时，还会提醒它可能把同一个软件里你没选的部分也删掉。你明确回复“确定删除”，它才开始；Windows 弹出窗口问你是否允许时点“是”。没说的编号都保留，“都删了吧”也只包括“可以删除”的。

  5. 5

    自己重启，再让它检查

    它会照实告诉你删掉了什么、还剩什么、要不要重启，不会把“没删掉”“不确定”说成完成。它不会替你重启电脑：保存工作后自己重启，再告诉它“重启好了”；换了新的对话，就说“帮我检查上次删除的结果”。

网页版豆包等不能运行本机命令的 Agent，碰不到你的电脑：请让它引导你用下面的“开始检查”窗口，它可以帮你看懂窗口里的文字。见 豆包指南；完整的示例对话和提示词见 README。

Agent 不能运行本机命令时

双击“开始检查”，六步走完，每一步都由你决定

  1. 1

    下载并全部解压

    点上面的“下载 ZIP”。在下载好的 ZIP 上点右键，选“全部解压缩”（有的电脑显示为“全部解压”），再打开解压出来的文件夹。不要直接在压缩包里运行，也不要用来路不明的修改版。

  2. 2

    双击“开始检查”

    双击 开始检查（文件名 开始检查.cmd，内容相同的英文名是 Start-Check.cmd）。打开后先检查电脑，不删除任何东西，窗口只显示当前这一步和已用时间，通常一两分钟。点“停止检查”会停下来，这次结果不会使用。

  3. 3

    看懂结果，自己勾选

    结果按软件分组，打开时一个都不勾选。“删不删”这一列只有两种答案：“可以删除”由你决定删不删；“不删除：原因”的不能勾选。点任意一行，下方会说明它是什么、删除后会怎样。“全选可以删除的”只会勾选可以删除的，为了安全只会少选、不会多选。不想删，直接点“关闭”。

  4. 4

    确认要删除的内容

    点“删除选中的内容…”。如果勾选需要调整（例如超过 64 项），工具会先说明怎么改，这时还没有删除任何东西。“确定要删除吗？”窗口会写明：删除后不能恢复，也不会放进回收站；你没选的会保留（勾选了 360 自带的卸载程序时，会单独提醒它可能删掉同一个软件里没选的部分）。先关闭 360 的软件、备份需要的书签，再点红色的“删除”，并在 Windows 弹出的窗口里点“是”。拿不准就点默认的“取消”。

  5. 5

    看结果，手动重启电脑

    开始删除后不能中途停止，请等它结束。结果页用一个大标题告诉你删掉了没有，例如“删除完成”“还差一步：请重启电脑”“有些没删掉”“不确定有没有删干净”，并写明接下来怎么做；没删掉、不确定、要重启的结果不会显示成成功。工具不会自动重启电脑，请保存工作后自己重启。

  6. 6

    重启后检查上次删除的结果

    再次双击“开始检查”，在“上次删除的记录”里点“检查上次删除的结果”。检查只读取信息，不会删除任何东西；你保留的内容会放在“你保留的”里，不算删除失败。

读懂“删不删”

每一项只有两种答案：可以删除，或者不删除

窗口和 Agent 用同一套说法。判断来自本机的位置、安装记录、定时任务、后台服务、数字签名或文件内容，不是只看名字里有没有“360”。

可以删除
这是 360 留下、可以删掉的东西。可以在窗口里勾选，或者在对话里说出它所在软件的编号（说编号会选这个软件里写着“可以删除”的项目，为了安全只会少选，确认内容里会列出来；只想删其中几项，请用“开始检查”窗口）。窗口不替你决定；Agent 可能会说“建议删除”，你还在用的它会先问你。只有你确认的才会删，没选的都保留。
不删除：原因
例如名字或位置像 360，但不能确定是 360 的。这些内容只显示原因，不能勾选，Agent 也不会建议删除或想办法绕过：不删除：不能确定是 360 的 · 不删除：书签和历史记录 · 不删除：在另一个 Windows 系统里 · 不删除：系统驱动 · 不删除：这是别的软件 · 不删除：信息不完整 · 不删除：请先正常卸载

不会删除的

正常文件和个人资料不会因为一个名字就被处理

普通数字文件

照片、游戏资源、模型、哈希值和其他只在名称中含有“360”的内容，不算 360 软件的证据。

Windows 与驱动

系统屏保、显卡和网卡驱动、驱动精灵等正常软件不会因为关键词被删。360 的系统驱动只列出来，不会删除。

浏览器个人资料

浏览器程序和个人资料是两个单独的项目。书签、历史记录等个人资料显示为“不删除：书签和历史记录”，在“开始检查”的窗口里不能勾选，Agent 也不会把它算进要删除的内容。

其他 Windows 系统

另一块磁盘上的 Windows 只检查、只列出来；本项目不提供跨系统删除。

隐私与求助

结果留在本机；求助前先检查要发的文字

本介绍页没有分析、广告或跟踪脚本。检查、删除和重启后的再次检查都在你的电脑上运行，工具不会上传任何内容。记录文件是 JSON 文件，默认保存在桌面，文件名类似 360-cleanup-scan-….json；你不需要打开它们，窗口和 Agent 都会用大白话说明。

需要求助时，在窗口的结果页点“获取帮助”。它会另外生成一份问题信息，尽量隐藏用户名、计算机名、SID、邮箱和私人路径，但可能有遗漏；你可以先修改，发出前请逐行检查。原始记录不会被修改，这份文字也不能用来删除任何东西。“打开求助网页”只会打开浏览器里固定的求助页面，不会替你发送。

常见问题

开始前最值得确认的事

它是“一键清理软件”吗？

不是。它先检查电脑，告诉你每一项删不删，只删除你亲自确认的内容。窗口打开时一个都不勾选，“全选可以删除的”也只在你自己点它时才勾选；Agent 可以建议，但只删除你说出的编号。

一定要用 AI Agent 吗？

不一定。推荐用能在电脑上运行命令的 Agent（例如 Codex），它会按 SKILL.md 检查，再用大白话告诉你删不删。Agent 碰不到你的电脑（例如网页版豆包），或者你不用 Agent，就双击“开始检查”，说法完全一样。豆包用法见豆包指南。

Agent 说“建议删除”，我一定要删吗？

不用。建议只是建议，只有你说出的编号才会删除，没说的都保留。删除前它必须先给你看确认内容，等你明确回复“确定删除”。它说“完成了”却拿不出真实的检查结果，就不要相信。

需要安装什么或管理员权限吗？

不需要安装。Windows 10/11 自带 Windows PowerShell 5.1。检查不需要管理员权限；只有你确认删除时，Windows 才会弹出窗口问你是否允许。

它能检查哪些软件？

360 安全卫士/360 杀毒、360 安全浏览器和 360 极速浏览器、360 软件管家、360 画报/多绘屏保、winToolBox 里的 360 程序文件，以及相关的开机自动运行、后台服务和定时自动运行的任务。不保证覆盖所有版本，具体范围见检测目录。

只删了一部分，再检查时会算失败吗？

不会。“检查上次删除的结果”分成“没删掉”“没法确认或没检查完”“新找到的或有变化的”“你保留的，但不见了”“你保留的”和“已删掉”。你保留的内容还在是正常的，不算失败。检查不会删除任何东西；想处理新找到的内容，请重新检查电脑，再自己决定。

在 Windows 弹出的窗口里点了“否”，或显示“不确定有没有删干净”怎么办？

点了“否”时不会删除任何东西，窗口的结果页显示“没有删除任何东西”。“不确定有没有删干净”表示没法确认，不要当作已经删干净：保存工作、手动重启后再检查（窗口里点“检查上次删除的结果”，对话里告诉 Agent “重启好了”）；还是没法确认时，点“获取帮助”。

会自动重启、开机自启或上传数据吗？

不会。工具和 Agent 都不会替你重启电脑，工具不会开机自启，不会常驻后台，也不会上传任何内容。需要重启时，只会提示你自己动手。

怎么求助才不泄露隐私？

点“获取帮助”，逐行检查后再复制或保存，然后在 GitHub Issue 里粘贴。不要直接公开原始记录文件，也不要附上没检查过的截图。
