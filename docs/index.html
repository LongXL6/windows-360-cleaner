清理 360 软件，从一次扫描开始

Windows 360 Cleaner 既支持 Agent 按规则协助，也提供无需 Agent 的双击流程。 它先在本机扫描，把证据充分的目标与待人工判断的项目分开；只有你审阅报告并明确批准后，才会处理仍然匹配的精确目标。

第一次使用

按顺序完成四步，不要跳过报告审阅

  1. 1

    下载并解压

    从官方 GitHub 仓库下载 ZIP，完整解压后再运行脚本。不要使用不明转载或修改版。

  2. 2

    先运行 Scan

    双击 scripts\Scan-360.cmd。Scan 是只读审计，不需要管理员权限，也不会删除文件。

  3. 3

    审阅 JSON 报告

    逐项查看路径、证据和分类。不要把文件名里出现“360”当作可删除依据。

  4. 4

    明确批准后再 Remove，重启后 Verify

    Remove 只处理已批准且仍被确认的目标。删除是永久操作；完成后建议重启 Windows，再运行 Verify 检查是否仍有 Confirmed 项。

需要逐步说明、Agent 提示词和故障处理？ 打开完整中文新手指南。

读懂扫描结果

两个标签，代表两条完全不同的处理边界

分类来自本机路径、产品记录、任务、服务、签名或文件证据。它不是只看名字的模糊匹配。

Confirmed
检测证据满足项目规则。它仍然不会自动删除；你必须先看清精确目标并明确批准。
ReviewOnly
证据不足、目标含糊、属于驱动或来自离线 Windows。项目只报告，不会自动删除。

默认保留

正常文件和个人资料不会因为一个名字就被处理

普通数字文件

照片、游戏资源、模型、哈希值和其他只在名称中含有“360”的内容不构成产品证据。

Windows 与驱动

系统屏保、显卡和网卡驱动、驱动精灵及其他正常软件不会因为关键词被强删。

浏览器个人资料

书签、历史记录和会话默认保留。删除浏览器资料需要单独备份、扫描选项和明确批准。

其他 Windows 安装

另一块磁盘上的 Windows 只允许扫描和报告；本项目不提供跨系统删除模式。

隐私与报告

结果留在本机；公开求助前先检查报告

本介绍页没有分析、广告或跟踪脚本。项目的 Scan、Remove 和 Verify 在本机 PowerShell 中运行，并把结果写入本地 JSON 报告。

报告中的电脑名和用户字段默认留空，但批准上下文、用户 SID 和发现路径仍可能暴露身份。 保留未经修改的本机 Scan 原件供 Remove 使用；公开求助时另做脱敏副本，不能用修改过的副本继续 Remove。

常见问题

开始前最值得确认的事

它是“一键清理软件”吗？

不是。它是给 AI Agent 使用的技能包，也提供可双击的备用脚本。核心流程始终是先扫描、人工审阅，再决定是否删除。

它能检查哪些软件或问题？

当前规则覆盖有证据支持的 360 安全卫士、360 浏览器卸载残留、360 画报/多绘屏保（Huabao/Duohui）和相关更新任务， 但不保证覆盖所有版本或变体。具体范围见 检测目录。

Scan 会删除目标软件吗？

不会。Scan 不要求管理员权限，也不会删除目标软件；它会在本机新建一份待审阅的 JSON 报告。

看到 ReviewOnly 应该怎么办？

不要手工强删。先保留目标，核对签名、版本和路径；仍无法判断时，提交带脱敏证据的 GitHub Issue。

Remove 成功就代表彻底清理了吗？

不一定。Remove 的动作报告和重启后的 Verify 是两个证据阶段。最终应查看 Verify 报告里是否仍有 Confirmed 项。

必须使用 AI Agent 吗？

不必须。可以下载 ZIP，按中文新手指南运行 Scan、审阅报告，再决定是否使用 Remove 和 Verify。
