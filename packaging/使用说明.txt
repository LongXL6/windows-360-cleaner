Windows 360 清理工具 v{{VERSION}} 使用说明
==========================================

一、这是什么
------------
这是一个免费开源的 AI Agent 技能包，也带一个本地窗口。它检查电脑上的 360 / 奇虎软件和它们留下的东西，
用大白话告诉你每一项“可以删除”还是“不删除”，并且只删除你自己确认过的内容。

- 检查电脑、检查上次删除的结果，都不会删除任何东西。
- 没有你的明确确认，什么都不会删：在窗口里，要你勾选、看完“确定要删除吗？”窗口并点“删除”；
  在 AI Agent 对话里，要你看过确认内容并回复“确定删除”。之后 Windows 还会问你是否允许，点“是”才开始删除。
- 工具不会联网上传，不会自动重启电脑，也不会一直在后台运行或开机自动运行。

二、两种用法（选一种）
--------------------
A. 用 AI Agent（推荐）
   你的 AI Agent 能在这台电脑上运行 PowerShell 时（例如 Codex），把这个文件夹交给它，
   让它先读取文件夹里的 SKILL.md，然后对它说：
     帮我检查这台电脑上的 360 软件，用大白话告诉我哪些建议删除、哪些不删除，只删除我确认的。
   它会先检查，再按编号告诉你哪些建议删除、哪些不删除。你回复编号（例如“删除 2”），
   它会先给你看确认内容；你明确回复“确定删除”，它才开始删除。
   “建议删除”只是建议，没说的编号都保留；写着“不删除”的，它不会建议删除，也不会想办法绕过。
   它不会替你重启电脑。删完后保存好正在做的事、自己重启，再告诉它“重启好了”，它会再检查一遍。
   它说“完成了”却拿不出真实的检查结果时，不要相信。

B. 用本地窗口
   Agent 不能运行本机命令（例如网页版豆包），或者你不用 Agent 时，按下面“四、窗口使用步骤”做。
   网页版豆包可以帮你看懂窗口里的文字，但勾选和删除要你自己在窗口里完成。

三、使用前需要什么
------------------
- Windows 10 或 Windows 11。
- 系统自带的 Windows PowerShell 5.1（Windows 10/11 默认就有，不用另外安装）。
- 本工具不用安装，解压后直接使用。
- 删除时 Windows 会弹出窗口问你是否允许，点“是”才会继续。

四、窗口使用步骤
----------------
1. 全部解压
   在下载的 ZIP 文件上点右键，选择“全部解压缩”（有的电脑显示为“全部解压”），
   解压到容易找到的位置，比如桌面。
   不要在压缩包里直接双击运行，否则会提示“没有找到 scripts 文件夹中的程序文件”。

2. 双击“开始检查”
   打开解压后的文件夹，双击“开始检查”（英文名相同的文件是 Start-Check，两个完全一样）。
   窗口标题会显示版本号 v{{VERSION}}。
   如果 Windows 提示“无法验证发布者”或“Windows 已保护你的电脑”，这是因为脚本没有数字签名。
   请先确认 ZIP 是从本说明最后的项目主页下载的；不确定就不要运行。

3. 等检查完，看结果
   第一次打开会自动开始检查电脑，检查不会删除任何东西，可以随时点“停止检查”。
   检查完后，结果按软件分组列出，每一行后面写着“可以删除”，或者“不删除：原因”。
   点某一行，窗口下方会用大白话说明它是什么、删除后会怎样。

4. 自己决定删不删
   打开时一个都不勾选。你可以只勾选自己确定不要的内容；没勾选的，本工具不会去删。
   窗口里的“可以删除”只说明可以删，不是建议删除，删不删由你自己决定。
   写着“不删除”的内容不能勾选，本工具不会删除它们。
   “全选可以删除的”只会勾选可以删除的内容，为了安全只会少选、不会多选，删除前还要再确认一次。
   如果看不懂，可以什么都不勾选，直接点“关闭”。

5. 确认
   点“删除选中的内容…”后，会弹出“确定要删除吗？”窗口，列出要删除的内容、删除后会怎样和会保留的内容。
   请先关闭 360 的软件；如果要删除浏览器相关的内容，先备份书签。
   确认无误后点“删除”（直接按回车只会“取消”），Windows 会再弹出窗口问你是否允许，点“是”。
   开始删除后不能中途停止，请耐心等待，也不要关闭窗口或关机。

6. 看删除结果
   结果页用一个大标题告诉你：“删除完成”“还差一步：请重启电脑”“有些没删掉”“不确定有没有删干净”
   或“没有删除任何东西”，下面写着接下来怎么做。
   有些文件正在被使用，需要重启电脑后才能删完，这很常见。

7. 保存工作后手动重启
   先保存好正在编辑的文档，再自己重启电脑。本工具不会自动重启。

8. 重启后检查上次删除的结果
   再次双击“开始检查”，在首页点“检查上次删除的结果”。（如果上次删除没有留下有效的结果，
   就不会出现这个首页，工具会直接开始重新检查电脑。在 AI Agent 对话里删除的，窗口首页不会显示；
   这时如果首页出现，显示的是更早一次在窗口里的删除，请看上面的时间。在对话里删除的，请回到 Agent 那里检查。）
   检查不会删除任何东西。结果按下面几类列出：
   - 没删掉
   - 没法确认或没检查完
   - 新找到的或有变化的
   - 你保留的（还在，这是正常的，不算失败）
   - 你保留的，但不见了（比如被 360 自带的卸载程序一起删了；还需要的话请重新安装）
   - 已删掉
   如果还有想处理的内容，可以点“重新检查电脑”，再自己决定。

五、安全须知
------------
- 打开时一个都不勾选，删不删完全由你决定；Agent 也不会替你选。
- 窗口里的“可以删除”不是建议删除；Agent 说的“建议删除”也只是建议，都不代表你已经同意删除。
- 浏览器书签、历史记录、保存的密码等个人资料不删除，不能在这里直接删除。
- 删除是永久的，不会放进回收站，删除前请确认并备份重要资料。
- 如果选了“360 自带的卸载程序”，它可能把同一个软件里你没选的部分也一起删掉。
- 工具不会自动重启，也不会上传任何内容。
- 需要别人帮忙时，请在窗口里点“获取帮助”。问题信息会尽量隐藏用户名、电脑名等信息，
  但可能有遗漏，请逐行检查一遍，确认没有私人信息后，再发给别人。
- 不要把原始记录文件公开发给别人，里面可能有你电脑上的文件位置。

六、记录保存在哪里
------------------
检查、删除和检查上次删除结果的记录保存在桌面上，文件名类似：
  360-cleanup-scan-日期-时间-编号.json（检查电脑的记录）
  360-cleanup-remove-日期-时间-编号.json（删除的记录）
  360-cleanup-verify-日期-时间-编号.json（检查上次删除结果的记录）
  360-cleanup-task-日期-时间-编号.json（窗口里这次删除选了哪些，只用来检查结果，不是删除批准）
  360-cleanup-help-日期-时间-编号.txt（你保存的问题信息）
如果桌面不可用，会保存在临时文件夹（%TEMP%）。
点“获取帮助”，再点“打开记录所在文件夹”，就能直接找到它们。记录不会被覆盖，也不会自动上传。
你不需要打开这些记录，窗口和 Agent 都会用大白话说明。

七、需要帮助
------------
1. 在结果页或出错页点“获取帮助”。
2. 逐行检查问题信息，删掉你不想让别人看到的内容。
3. 点“复制”或“保存成文件”后，再发给愿意帮助你的人，或者点“打开求助网页”在项目主页提交求助（Issues）。

English (short)
===============
Windows 360 Cleaner v{{VERSION}} is an AI agent skill with a local window. It finds 360 / Qihoo software and what it
left behind on Windows 10/11, tells you in plain words whether each item "can be deleted" or "won't be deleted", and
deletes only what you confirm. It uses the built-in Windows PowerShell 5.1 and needs no installation.

With an AI agent (recommended), if it can run PowerShell on this PC:
- Give it this folder, ask it to read SKILL.md first, and say: "Check this PC for 360 software, tell me in plain words
  what you suggest deleting and what won't be deleted, and delete only what I confirm."
- It numbers the products and says what it suggests deleting. Reply with numbers; it shows you a confirmation text,
  and deletes only after you explicitly reply "yes, delete". Numbers you do not name are kept.
- It never restarts the PC. Restart yourself, then tell it "it has restarted" and it checks again.

With the window (if your agent cannot run local commands, or you do not use one):
1. Right-click the downloaded ZIP and choose "Extract All". Do not run it from inside the ZIP.
2. Double-click "Start-Check" (or the identical Chinese-named launcher) in the extracted folder.
3. Wait for the check to finish. Checking never deletes anything; you can click "Stop checking" at any time.
   Every row says "Can be deleted" or "Won't delete: <reason>".
4. Decide for yourself what to tick. Nothing is ticked when the page opens; the tool does not delete unticked items.
   "Select all deletable" ticks only items that can be deleted and only ever selects less for safety.
5. Click "Delete selected...", read the "Delete these items?" window and click "Delete" (Enter only cancels).
   Windows asks for permission; click "Yes". Deleting cannot be stopped once it has started.
6. Read the result page.
7. Save your work and restart the PC yourself. The tool never restarts automatically.
8. Double-click "Start-Check" again and click "Check the last deletion". (If the last deletion left no valid result,
   that home page does not appear and the tool checks the PC again instead. A deletion made in an agent conversation
   is never shown there; if the page appears anyway, it is an earlier deletion made in the window, so check its time.
   Check a deletion made in a conversation with the agent.)

Safety notes:
- "Can be deleted" only means it belongs to 360 and can be deleted; an agent's suggestion is not your approval.
- Browser bookmarks and other personal data are not deleted.
- Deletion is permanent and does not use the Recycle Bin.
- If you choose an uninstaller that came with 360, it may also remove parts of that product you did not choose.
- The tool uploads nothing. For help, click "Get help", review the text line by line, then share it.

Records are saved on your Desktop as 360-cleanup-*.json (fallback: %TEMP%).
