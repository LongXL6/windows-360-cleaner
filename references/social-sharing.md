## 发布时统一的事实边界

- Windows 360 Cleaner 首先是一个开源的 AI Agent Skill 技能包，也带一个本地窗口：能在电脑上运行命令的 Agent 读取 `SKILL.md` 使用；Agent 碰不到电脑时（例如网页版豆包），用户下载并全部解压后双击“开始检查”使用窗口。它不是一键清理软件，也不是杀毒软件。
- Agent 路线的统一流程是：`Scan（检查）→ Show-360Summary.ps1 用大白话说明每个软件“可以删除 / 不删除” → 用户说出编号 → 展示确认内容，用户明确回复“确定删除” → Remove → 用户手动重启 → Verify（检查上次删除的结果）`。窗口路线对应为：双击“开始检查”（检查）→ 看每一行“删不删”、自己勾选 → 在“确定要删除吗？”窗口里点“删除” → 手动重启 → “检查上次删除的结果”。
- 检查不会删除任何东西；写着“不删除”的内容不能选；浏览器个人资料默认保留。窗口打开时一个都不勾选，“全选可以删除的”只选可以删除的，并且为了安全只会少选、不会多选。Agent 可以说“建议删除”，但建议不是批准：只有用户说出的编号才会删除。
- `Remove` 是永久操作，不进回收站：窗口里要用户亲自勾选并确认，对话里要用户看过确认内容并明确回复“确定删除”；之后 Windows 弹出窗口问是否允许时还要点“是”。
- 结果会写明删掉了什么、没删掉什么、不确定什么、要不要重启。其中的文件逻辑大小不等于磁盘真实新增可用空间。
- 不声称“一键清干净”、“保证安全”、“保证不误删”或“真实释放 XX GB”；不虚构使用前后对比。
- 不暗示发布者自己安装过某个产品。如引用案例，要明确写成“项目文档记录的已观察链路”，不扩大到所有电脑。

## 小红书图文草稿

### 标题候选

1. 别再搜 `*360*` 强删了：让 AI 先检查，再告诉你删不删
2. 电脑里的 360 该删哪些？让 Agent 用大白话告诉你
3. 一个不代替你点“删除”的 AI 清理 Skill

### 正文

Windows 里的数字 `360` 可能出现在软件、游戏资源、全景照片或哈希中，所以“搜名字后全删”很容易伤到无关文件。

Windows 360 Cleaner 是一个开源的 AI Agent Skill。对能在电脑上运行命令的 Agent 说一句“帮我检查这台电脑上的 360 软件”，它会先检查（检查不会删除任何东西），再用大白话告诉你：每个 360 软件是“可以删除”还是“不删除”，以及为什么。你还在用的软件，它会先问你。

完整流程是：

1. Agent 检查电脑，不删除任何东西。
2. 按编号告诉你哪些建议删除、哪些不删除。
3. 你说要删的编号，它先给你看确认内容：要删什么、删除后会怎样、删了不能恢复。
4. 你明确回复“确定删除”，Windows 弹出窗口问是否允许时点“是”，才开始删除。
5. 自己手动重启电脑后，告诉 Agent “重启好了”，它再检查一遍（检查不会删除任何东西）。

没有能运行命令的 Agent 也可以用：下载并全部解压 ZIP，双击“开始检查”，窗口里每一行都写着“可以删除”或“不删除：原因”，打开时一个都不勾选，自己勾选、确认后才删除。

它不是杀毒软件，不保证覆盖所有历史或未来版本。浏览器书签、历史和会话等个人资料默认保留。

## 微信公众号短稿

### 标题

别再按文件名强删：一个先检查、再由你确认的 Windows 360 清理 Skill

### 摘要

Windows 360 Cleaner 把“检查”、“决定”和“验证”分开：Agent 用大白话告诉你删不删，真正删除只按你的确认来。

### 正文

直接搜索并强删所有名称含 `360` 的文件，会把正常软件、游戏资源、全景媒体和 Windows 文件一起卷进来。这个项目使用精确路径、产品证据和持久化动作来判断哪些内容真的属于 360 软件。

它是 AI Agent 的 Skill 技能包，而不是一键杀毒工具。第一步始终是检查，检查不会删除任何东西。之后 Agent 运行项目自带的 `Show-360Summary.ps1`，把结果翻译成大白话：每个 360 软件要么“可以删除”，要么“不删除：原因”（例如不能确定是 360 的、是书签和历史记录、软件还装着要先正常卸载）。Agent 可以说“建议删除”，但只有你说出的编号才会进入删除；删除前它必须先给你看确认内容，等你明确回复“确定删除”。

删除会写明删掉了什么、没删掉什么、不确定什么，不会把“要重启才能删完”或“不确定”说成完成。文件逻辑大小不等于磁盘实际新增可用空间。服务或 Explorer 扩展可能需要重启 Windows，最终状态要以重启后的检查为准，工具不会替你重启。

没有能运行命令的 Agent 时，可以下载解压后双击“开始检查”使用本地窗口，说法完全一样。项目默认保留浏览器书签、历史和会话等个人资料，也不把驱动、游戏目录或全景照片当成目标。它无法保证覆盖所有历史、地区或未来变体，所以证据不足的项目只会显示为“不删除”。
