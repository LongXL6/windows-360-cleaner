## 这是什么

这是一个免费、开源的 **AI Agent 技能包**，也带一个本地窗口。它检查电脑上的 360 系列软件和它们留下的东西，用大白话告诉你每一个是 **可以删除** 还是 **不删除**，然后**只删除你亲自确认过的内容**。

有两种用法，说法完全一样：

| 你的情况 | 怎么用 |
|---|---|
| 你在用能在这台电脑上运行命令的 AI Agent（例如 Codex） | **推荐。** 直接对 Agent 说“帮我检查这台电脑上的 360 软件”。它会告诉你哪些建议删除、哪些不删除，等你确认后才删除。见 [用 AI Agent 使用](#用-ai-agent-使用推荐) |
| Agent 不能运行本机命令（例如网页版豆包），或者你不用 Agent | 下载解压后双击 **开始检查**。窗口里每一行都写着“可以删除”或“不删除：原因”，你自己勾选、确认。见 [双击“开始检查”](#agent-不能运行本机命令时双击开始检查) |

它能找出这些内容：

- 360 安全卫士、360 杀毒
- 360 安全浏览器、360 极速浏览器、360 极速浏览器 X
- 360 软件管家
- 360 画报 / 多绘屏保
- 第三方工具箱 winToolBox 里带的 360 程序文件
- 和上面这些软件有关的开机自动运行、后台服务、定时自动运行的任务等

你只需要记住三件事：

- **检查不会删除任何东西。**
- **没有你的明确确认，什么都不会删。** Agent 可以说“建议删除”，窗口打开时一个都不勾选；删不删、删哪些，只由你决定。
- **它不会自动重启电脑，不会开机自启，不会常驻后台，也不会上传任何内容。**

它不是杀毒软件，不会查杀病毒，也不会删除“名字里带 360”的普通文件。

## 系统要求

| 项目 | 说明 |
|---|---|
| 系统 | Windows 10 或 Windows 11 |
| 需要安装什么 | 不需要。它使用 Windows 自带的 Windows PowerShell 5.1，本工具解压后直接用 |

| 语言 | 窗口：Windows 显示语言是中文时显示中文，否则显示英文。Agent：按你说话的语言回复 |

## 用 AI Agent 使用（推荐）

这个仓库首先是一个 **AI Agent 技能包**。Agent 按 [SKILL.md](SKILL.md) 运行检查，再用 `scripts\Show-360Summary.ps1` 把结果变成大白话告诉你。Agent 和窗口用的是同一套文字，所以你听到的只会是“可以删除”或“不删除”，以及为什么。

核心规则只有一句：**Agent 可以检查、解释、给建议，但删不删、删哪几个，只能由你来说。**

### 1. 让 Agent 用上这个技能

- **Codex**：把整个仓库复制到 `%USERPROFILE%\.codex\skills\windows-360-cleaner`，然后说 `$windows-360-cleaner 帮我检查这台电脑上的 360 软件`。
- **其他能运行本机命令的 Agent**：把仓库地址 `https://github.com/LongXL6/windows-360-cleaner` 发给它，让它先完整读取 `SKILL.md`。
- **不知道 Agent 能不能运行命令**：先问它“你能在这台 Windows 电脑上运行 PowerShell 吗？”。不能的话，用下面的 [开始检查窗口](#agent-不能运行本机命令时双击开始检查)。

### 2. 对 Agent 说什么

一句话就够：

```text
帮我检查这台电脑上的 360 软件，用大白话告诉我哪些建议删除、哪些不删除，只删除我确认的。
```

想让 Agent 更严格地照规则做，可以复制下面的 [完整提示词](#复制给-agent-的完整提示词)。

### 3. Agent 会怎么回复

下面是一段示例对话。数据是示例，Agent 说的话来自 `Show-360Summary.ps1` 的真实输出（Agent 可能会稍微缩短，“建议删除”和“你还在用吗”是 Agent 自己加的建议）：

```text
你：    帮我检查这台电脑上的 360 软件

Agent： 检查完了（检查不会删除任何东西）。找到 2 个可以删除的 360 软件：
        1. 360 安全浏览器 —— 可以删除（1 项），1 项不删除
           书签和历史记录不删除。你还在用 360 安全浏览器吗？不用的话建议删除。
        2. 360 画报 / 多绘屏保 —— 可以删除（3 项），建议删除
           删除后：多绘屏保和它的壁纸功能不能再使用。会运行多绘屏保自带的卸载程序，它删掉的东西找不回来。
        这些不删除：
        3. 360 临时文件 —— 不删除：不能确定是 360 的
        要删除哪几个？回复编号就行，比如“删除 1”或“删除 1 和 2”。没说的都会保留。

你：    删除 2

Agent： 好的。删除前请再看一眼：
        要删除的（3 项）：360 画报 / 多绘屏保（多绘屏保安装文件夹、多绘屏保临时安装包、运行多绘屏保自带的卸载程序）
        删除后：多绘屏保安装文件夹和里面的东西会全部删掉，多绘屏保和它的壁纸功能不能再使用；临时安装包只是临时文件；会运行多绘屏保自带的卸载程序，它删掉的东西找不回来。
        你没选的（本工具不会删）：360 安全浏览器、360 临时文件
        删除后不能恢复，也不会放进回收站。
        你选的内容里有 360 自带的卸载程序，它可能会把同一个软件里你没选的部分也一起删掉。
        删除前请先关闭 360 的软件，需要的书签等资料请先备份。
        开始删除时，如果 Windows 弹出窗口问你是否允许，请点“是”。
        确定要删除吗？回复“确定删除”我再开始。

你：    确定删除

Agent： 删除完成
        你选的都删掉了。因为运行了 360 自带的卸载程序，同一个软件里你没选的部分可能也被删掉了。
        删掉 3 项，没删掉 0 项，不确定 0 项。
        接下来：建议找个方便的时候重启一次电脑，重启前先保存好正在做的事（我不会替你重启）。重启好了告诉我，我再检查一遍有没有删干净。

你：    重启好了

Agent： 上次选的都删干净了
        上次选的 3 项都确认删掉了。你保留的内容还在，这是正常的。
        接下来：不用再做什么了。
```

### 4. 用 Agent 时要知道的事

- **“建议删除”不是替你决定。** 只有你说出的编号才会删除，没说的都保留。“都删了吧”只包括写着“可以删除”的；你可能还在用的软件（例如浏览器、360 安全卫士），Agent 会先问你。
- **写着“不删除”的，Agent 不会建议删除，也不会想别的办法去删。**
- **删除前一定先给你看确认内容。** 你明确回复“确定删除”，Agent 才会开始；想改的话重新说编号，它会重新给你看。
- Windows 弹出窗口问你是否允许时，确认是你刚才同意的删除，再点“是”；点“否”就不会删除任何东西。不过 Agent 没法确认你点的是“否”，会照实说“不确定有没有删干净”，请你重启后再检查，照做就行（检查不会删除任何东西）。
- **删除开始后不能中途停止**，也不要让 Agent 再运行一次。
- **Agent 不会替你重启电脑。** 保存好正在做的事，自己重启，再告诉它“重启好了”。如果已经换了新的对话，就说“帮我检查上次删除的结果”，它会先找到上次的删除记录再检查。检查不会删除任何东西。
- 没删掉、不确定、要重启时，Agent 必须照实说，不能说成“完成了”。Agent 说完成了却拿不出真实的检查结果，不要相信。
- 想看删掉了多少文件、多大等细节，直接问它要“详细信息”。
- 在对话里删除的，重启后请回到 Agent 那里检查；“开始检查”窗口首页的“上次删除的记录”只记得在窗口里做的删除。如果首页出现了“上次删除的记录”，那是更早一次在窗口里的删除，请看上面的时间。

### 复制给 Agent 的完整提示词

```text
请使用 https://github.com/LongXL6/windows-360-cleaner，先完整读取 SKILL.md，按其中的安全规则执行，并按 “Talking to the user” 的方式跟我说话。
先告诉我你能否真正操作这台 Windows 电脑的 PowerShell。不能操作时，不要声称已经检查过，请让我完整解压 ZIP 后双击根目录的“开始检查.cmd”。
能操作时：先运行检查（Scan，不会删除任何东西），再运行 scripts\Show-360Summary.ps1，用它的大白话告诉我每个 360 软件“可以删除”还是“不删除”和原因。可以删除的可以建议删除；我可能还在用的先问我；不删除的不要建议删除，也不要想办法绕过。不要把 AGENT: 开头的行、路径和技术词念给我。
删哪几个由我说编号，没说的都保留；“都删了吧”只算“可以删除”的。删除前把 Show-360Summary 为这些编号生成的确认内容给我看，等我明确回复“确定删除”才运行它给出的命令，只运行一次，不要自己改。不要按名字含 360 批量删除，浏览器个人资料默认保留。
删除后用 Show-360Summary 告诉我结果，提醒我保存工作并自己重启，不要自动重启。重启后运行检查（不会删除任何东西），再用 Show-360Summary 告诉我结果；如果是新的对话，先用 -FindLastRemove 找到上次的删除。
最后用几句话说清：删掉了什么、还剩什么或不确定什么、要不要重启和下一步。没删掉、不确定、需要重启不能说成完成；我保留的不算失败，我保留的东西不见了要告诉我。我要详细统计时会再问。
```

Agent 应先读取 [SKILL.md](SKILL.md)。需要判断检测证据时再读取 [检测目录](references/detection-catalog.md)，遇到锁文件或拒绝访问时再读取 [疑难排查](references/troubleshooting.md)。豆包和其他不支持 `$skill-name` 安装方式的 Agent 不需要修改技能名称，直接给它仓库链接并要求先读取 `SKILL.md` 就行。

### 豆包等不能运行本机命令的 Agent

网页版豆包这类聊天机器人，通常碰不到你电脑上的 PowerShell，也就没法替你检查或删除。这时请让它引导你用 [开始检查窗口](#agent-不能运行本机命令时双击开始检查)：窗口会用同样的大白话写明每一项“可以删除”还是“不删除”，删不删由你在窗口里勾选、确认。需要它帮忙看结果时，只把窗口里“获取帮助”生成、你逐行检查过的文字发给它；这段文字只用来讨论，不能用来删除任何东西。

```text
请把 https://github.com/LongXL6/windows-360-cleaner 当作一个 AI 技能包使用。先读取仓库根目录的 SKILL.md；不要只看 README，也不要搜索并强删所有名字含 360 的内容。
开始前先明确告诉我：你现在是否真的能访问这台 Windows 电脑的本机 PowerShell 并运行命令。不能就直说，不要把“给出命令”说成“已经执行”。
如果不能操作电脑：请让我下载并完整解压 ZIP，双击根目录的“开始检查”。打开后先检查、不删除，一个都不勾选。请帮我看懂窗口里每一行的“删不删”：“可以删除”表示这是 360 留下、可以删掉的东西；“不删除：原因”的不能勾选。我看不懂时，提醒我什么都不勾、直接点“关闭”。
我需要给你看结果时，只发窗口里点“获取帮助”生成、并由我逐行检查过的文字；原始记录文件留在我的电脑上。这段文字只用于讨论，不能用来删除任何东西。你可以告诉我哪些建议删除、哪些不删除，但要不要删除，由我自己在窗口里勾选和确认。
删除后提醒我保存工作、手动重启，再双击“开始检查”，点“检查上次删除的结果”。解释检查结果时，我保留的内容不算失败，没法确认的就说没法确认。
如果你确实能操作终端：先运行检查，再用 scripts\Show-360Summary.ps1 的大白话告诉我删不删；删除前把它为我说的编号生成的确认内容给我看，等我明确回复“确定删除”才运行它给出的命令，只运行一次；重启后运行检查并用 Show-360Summary 告诉我结果。最后用几句话说清删掉了什么、还剩什么或不确定什么、下一步做什么，不得编造。
```

更详细的路线、上传内容时的隐私提醒和故障处理见 [豆包与通用 Agent 使用指南](references/doubao.md)。

## Agent 不能运行本机命令时：双击“开始检查”

不用 Agent，或者 Agent 碰不到你的电脑时，用本地窗口。窗口里的说法和 Agent 一样：每一行只回答“删不删”。

1. 在下载好的 ZIP 文件上点右键，选择 **全部解压缩**（有的电脑显示为“全部解压”），按提示解压。**不要在压缩包里直接双击运行。**
2. 打开解压出来的文件夹，直到能看到 `开始检查` 和 `scripts` 文件夹。有时要再进一层同名文件夹，例如 `windows-360-cleaner-main`。
3. 双击 **开始检查**（完整文件名是 `开始检查.cmd`；旁边的 `Start-Check` 是英文名字的同一个入口，两个完全一样）。
4. 窗口打开后会自动开始**检查电脑**。检查不会删除任何东西。窗口标题会显示版本号，例如 `Windows 360 清理工具 v1.0.0`。

## 窗口完整流程：从检查到确认删干净

检查电脑 → 看每一行“删不删” → 自己勾选 → 确认 → 看删除结果 → 手动重启 → 检查上次删除的结果。

> [!NOTE]
> 下面的截图都使用**示例数据**（窗口顶部有黄色的“示例数据截图”横幅），截图时没有检查或删除任何真实内容。你电脑上看到的内容会不一样。

> [!IMPORTANT]
> **窗口不会替你决定删不删。** “可以删除”只说明这是 360 留下、可以删掉的东西；删不删、删哪几项，都由你自己勾选决定。

### 3. 自己决定删哪些

- 只勾选你确定不要的内容。**没勾选的，本工具不会去删。**
- 点软件前面的方框，会勾选这个软件里**可以删除、并且可以一起安全删除**的项目；再点一次就全部取消。
- **全选可以删除的** 只会勾选可以删除的内容，写着“不删除”的永远不会被勾选。它只会为了安全少选、不会多选。
- 有的内容单独看可以删，但在这次的检查结果里怎么选都没法安全删除：例如文件夹里面有要保留的东西，或者 360 自带的卸载程序所在的文件夹不能删。这样的行直接写着“不删除：里面有要保留的东西”或“不删除：要和它所在的文件夹一起删”，不能勾选，点软件行或“全选可以删除的”也不会选上。
- 少数情况下，点软件行时有的内容没有帮你选上（例如文件夹里面还有别的软件、你没勾选的内容），列表下方会用一句话说明。
- 窗口底部会显示 `已选 N 项要删除。`。一次最多删除 64 项。
- 如果你勾选了 **360 自带的卸载程序**，顶部那句话会变成橙色提醒：它可能把同一个软件里你没勾选的部分也删掉。

窗口底部的按钮：

| 按钮 | 作用 |
|---|---|
| `删除选中的内容…` | 至少勾选 1 项后才能点。先检查勾选，再打开“确定要删除吗？”窗口，这一步还不会删除 |
| `全选可以删除的` | 只勾选可以删除的内容，为了安全可能少选几项，不会多选 |
| `全部不选` | 取消全部勾选 |
| `获取帮助` | 生成一份尽量隐藏了个人信息的问题信息，方便向别人求助，见 [需要帮助](#需要帮助获取帮助) |
| `关闭` | 不删除任何东西，关闭窗口 |

点 `删除选中的内容…` 后，如果勾选需要调整，会先弹出“还需要调整一下”窗口，写明问题和怎么办。**这时还没有删除任何东西：**

- **一次勾选超过 64 项**：先取消一部分（例如一次只删一个软件），删完后重新检查电脑，再删下一批。
- **勾选了外面的文件夹，但里面还有你没勾选、可以单独删除的内容**：删除外面的文件夹会把它们一起删掉。可以点 `把这 N 项也选上`，或者不删外面的文件夹。
- **勾选了 360 自带的卸载程序，却没有勾选它所在的文件夹**：请把文件夹也勾上（出现 `把这 N 项也选上` 时点它），或者取消勾选卸载程序。

## “删不删”这一列怎么看

检查结果表里 `删不删` 这一列只有两种答案。**只有“可以删除”能勾选。** Agent 在对话里也用同样的说法。

| 显示 | 是什么意思 | 能勾选吗 |
|---|---|---|
| `可以删除` | 这是 360 留下、可以删掉的东西。窗口不替你决定；Agent 可能会建议删除，但删不删还是由你决定 | 可以，由你决定 |
| `不删除：不能确定是 360 的` | 名字或位置看起来像 360，但不能确定真的是 360 的。为了避免误删，不删除 | 不能 |
| `不删除：书签和历史记录` | 浏览器的书签、历史记录、保存的密码等个人资料 | 不能 |
| `不删除：在另一个 Windows 系统里` | 在电脑上的另一个 Windows 系统里（例如另一块硬盘上）找到的东西 | 不能 |
| `不删除：系统驱动` | 直接删除系统驱动可能导致蓝屏或开不了机 | 不能 |
| `不删除：这是别的软件` | 别的公司的软件里带了一部分 360 的东西。整个软件不删除，里面单独的 360 部分会另外列出来 | 整体不能 |
| `不删除：信息不完整` | 没能确认这一项的详细信息，为了避免删错，先不删除 | 不能，可以过一会儿重新检查电脑 |
| `不删除：请先正常卸载` | 这个软件看起来还装在电脑上。请先在 Windows“设置 → 应用”里卸载它，再重新检查电脑 | 不能 |
| `不删除：里面有要保留的东西` | 它本身可以删，但里面还有本工具不删除的东西，删它会把那些东西一起删掉 | 不能 |
| `不删除：要和它所在的文件夹一起删` | 360 自带的卸载程序要和它所在的文件夹一起删，而那个文件夹不能删 | 不能 |
| `不删除：请重新检查` | 这份检查结果来自旧版本的工具 | 不能，请重新检查电脑 |

## 删除结束会看到什么

结果页用一个大标题说明结果，下面一句说明，再告诉你“接下来”怎么做。失败、不确定、要重启的结果，**标题和颜色都不会像成功**。Agent 在对话里说的也是这几个标题（“没有删除任何东西”除外：Agent 没法确认你在 Windows 弹出的窗口里点了“否”，这时会说“不确定有没有删干净”）。

| 结果页标题 | 是什么意思 | 接下来 |
|---|---|---|
| `删除完成`（绿色） | 你选的都删掉了，删完后的再次检查也确认了。你没选的，本工具没有动 | 可以关闭；建议方便时保存工作并手动重启，再点“检查上次删除的结果” |
| `删除完成`（橙色） | 你选的都删掉了，但运行过 360 自带的卸载程序，或者有你没选的内容删完后没法确认还在不在，页面会写明 | 同上；你没选的内容如果还需要，重启后检查一下 |
| `还差一步：请重启电脑` | 有些东西正在使用，或后台服务在等重启，要重启电脑后才能删完 | 保存工作、手动重启，再点 `检查上次删除的结果` |
| `有些没删掉` | 有些内容没删掉，原因列在下面（相同原因的会合成一行）；或者删除程序没有正常结束 | 先重启电脑，再点 `检查上次删除的结果`；还是不行就点 `获取帮助` |
| `不确定有没有删干净` | 没有拿到可信的删除结果，或者删除后没能再检查一遍 | 不要当作已经删干净；重启后再检查 |
| `没有删除任何东西` | 例如你在 Windows 弹出的窗口里点了“否” | 可以重新检查电脑，或者直接关闭 |

- `删掉 N 项 · 没删掉 N 项 · 不确定 N 项` 这一行只在“删除完成”和“有些没删掉”时显示，不会出现在“不确定”“要重启”的结果下面。
- **详细信息** 窗口里有统计（删掉的文件、文件夹、后台服务、定时任务、360 留下的设置等）、没删掉或没做完的每一项、每一步的操作记录，以及 `打开记录所在文件夹`。
- **文件逻辑大小**不等于磁盘实际增加的可用空间。有些地方没法统计时，数字是最少值。

## 检查上次删除的结果怎么看

检查**不会删除任何东西**。列表只显示有内容的分组，按下面的顺序：

| 分组 | 放的是什么 |
|---|---|
| `没删掉` | 上次选了、现在还在的内容 |
| `没法确认或没检查完` | 检查时读不到、没法确认的内容，以及没检查完的地方 |
| `新找到的或有变化的` | 这次新找到的 360 内容，以及和上次不一样了的内容 |
| `你保留的，但不见了` | 上次没选、现在却不见了的内容（例如被 360 自带的卸载程序一起删了）。还需要的话请重新安装 |
| `你保留的` | 上次没选、现在还在的内容。**这是正常的，不算删除失败** |
| `已删掉` | 上次选了、直接查看过确认已经不在的内容 |

点 `检查上次删除的结果` 后，页面顶部的标题是下面之一：

| 标题 | 是什么意思 | 接下来 |
|---|---|---|
| `上次选的都删干净了` | 上次选的都确认删掉了（有保留的内容不见了时标题是橙色，说明里会写） | 可以关闭本工具 |
| `上次选的都删干净了，但有些地方没检查完` | 删掉了，但这次有些地方没检查完 | 过一会儿再检查一次 |
| `上次选的都删干净了，但又找到 N 项新的 360 内容` | 上次选的都删了，但这次又找到了新的 | 点 `重新检查电脑`，再决定删不删 |
| `还有 N 项没删掉` | 上次选的内容里，有的还在或者有变化 | 重启电脑后打开本工具再检查；还是删不掉就点 `获取帮助` |
| `有 N 项没法确认有没有删掉` / `上次选的看起来都删掉了，但这次检查没做完整` | 检查没能确认结果，不能当作已经删干净 | 重启电脑后打开本工具再检查；还是不行就点 `获取帮助` |
| `上次删除的记录用不了，已经重新检查了一遍电脑` | 例如上次的记录找不到、读不出来、版本不兼容，或者是另一个 Windows 用户删除的，所以没法逐项确认；页面显示的是重新检查电脑的结果 | 点 `重新检查电脑`，看看现在还有什么 |

没有上次删除的记录、直接检查整台电脑时（例如运行 `scripts\Verify-360.cmd`），标题是 `没有找到还需要处理的 360 内容`、`电脑上还有 N 项 360 的内容`、`没有找到还需要处理的 360 内容，但有些地方没检查完`，或者 `没有找到可以删除的 360 内容，但还有 N 项不删除的内容`（例如还装着、要先正常卸载的软件）。这时列表分为 `现在还有的 360 内容`、`没法确认或没检查完` 和 `不删除的`，不会把它们标成“新找到的”。

检查不需要 Windows 的允许。如果当初是用管理员身份检查和删除的，普通权限下看不到的定时任务、后台服务或读不到的程序，会显示在“没法确认或没检查完”里，不会被当作已经删掉。

## 需要帮助：获取帮助

检查结果页、删除结果页、检查上次删除结果的页面和出错页都有 `获取帮助` 按钮。

- 它会在你的电脑上**另外生成一份问题信息**，尽量隐藏用户名、计算机名、SID、邮箱和私人路径等信息，但可能有遗漏。
- 预览框里的文字可以修改。**发给别人之前，请逐行检查**，确认没有姓名、账号、私人文件夹等信息。
- 按钮：`复制`、`保存成文件`（文件名类似 `360-cleanup-help-….txt`，和记录放在同一个文件夹）、`打开求助网页`、`打开记录所在文件夹`、`关闭`。
- `打开求助网页` 只会打开浏览器里固定的求助页面，不会自动发送任何内容。在 GitHub 提交求助需要登录 GitHub 账号。
- 原始记录保持不变。问题信息只用于讨论，**不能用来删除任何东西**。本工具不会上传任何内容。

也可以直接 [打开求助页面](https://github.com/LongXL6/windows-360-cleaner/issues/new?template=help.yml)，把检查过的问题信息粘贴进去。不要上传原始记录文件。用 Agent 时，也可以先让 Agent 用大白话说明哪里出了问题。

## 本工具不会做的事

- **不会替你选择。** 窗口打开时一个都不勾选，“全选可以删除的”也只在你自己点它时才勾选；Agent 可以给建议，但只删除你亲口说出的编号。写着“不删除”的永远选不上。
- **不会不经你确认就删除。** 在窗口里，要你亲自勾选、看过“确定要删除吗？”窗口并点“删除”；在对话里，要你看过确认内容并回复“确定删除”。之后 Windows 还会弹出窗口问你是否允许。
- **不会按“名字里带 360”删除。** 只处理位置完全对得上、并且电脑上确实有这个 360 软件的内容。
- 写着“不删除”的内容（例如不能确定是 360 的、在另一个 Windows 系统里的、书签和历史记录），**不能在这里删除**。
- 浏览器书签、历史记录等个人资料**不删除**，和浏览器程序文件分开列出。
- 没删掉、不确定、要重启才能删完的结果，**不会说成成功**。
- **不会自动重启电脑，不会开机自启，不会常驻后台，不会上传任何内容。**
- 检查电脑和检查上次删除的结果，**都只读取信息**，不会删除任何东西。

> [!WARNING]
> 不要用“搜索所有名字含 `360` 的文件然后强删”这种方法。数字 360 可能出现在照片、游戏地图、模型、哈希值和 Windows 文件中。

默认不会删除的内容包括：

- 只是名字里含有数字 `360` 的文件或文件夹。
- Windows 自带屏保，例如 `Bubbles.scr`、`PhotoScreensaver.scr`、`scrnsave.scr`。
- 驱动精灵、显卡/网卡驱动、游戏目录和 Steam/iRacing 数字资源。
- `winToolBox` 里独立的看图、清理、PDF、压缩小工具（`kantu`、`clear`、`pdf`、`zip`）。
- 360 浏览器的个人资料（书签、历史记录、会话等）。
- 其他 Windows 系统里的任何文件。

## 常见问题

<details>
<summary><strong>我该用 Agent 还是“开始检查”窗口？</strong></summary>

你的 Agent 能在这台电脑上运行 PowerShell（例如 Codex），就直接对它说“帮我检查这台电脑上的 360 软件”，它会用大白话告诉你删不删。Agent 碰不到你的电脑（例如网页版豆包），或者你不用 Agent，就下载解压后双击 `开始检查`。两边说法一样，检查都不会删除任何东西，删除都要你亲自确认。

</details>

<details>
<summary><strong>Agent 说“建议删除”，我一定要删吗？</strong></summary>

不用。建议只是建议，只有你说出的编号才会删除，没说的都保留。你还在用的软件就不要删；拿不准就先不删。写着“不删除”的，Agent 不会建议删除。

</details>

<details>
<summary><strong>Agent 说“完成了”，但我不确定它真的检查过？</strong></summary>

有的聊天机器人只会写出命令，并没有真的在你电脑上运行。没有给你看检查结果、删除前也没有给你看确认内容，就不要当作已经检查或删除过。可以改用 `开始检查` 窗口。

</details>

<details>
<summary><strong>双击“开始检查”没反应，或者提示“没有找到 scripts 文件夹中的程序文件”？</strong></summary>

多半是没有全部解压。请在 ZIP 上点右键，选择“全部解压缩”，然后从解压出来的文件夹里双击 `开始检查`。不要只复制出一个 `开始检查.cmd`，也不要在压缩包里直接运行。

如果提示“本工具已经打开了。”，说明窗口已经打开了，请在任务栏里找到它。

如果弹出“Windows PowerShell 没能正常运行清理工具……”的提示，可能是被系统策略或安全软件阻止，也可能是文件损坏。不要为了运行本工具关闭安全防护；可以运行 `scripts\Scan-360.cmd` 查看具体错误，或把提示截图后求助。公司或学校电脑请联系管理员。如果弹出时正在删除，就不确定有没有删干净：请重启电脑后再双击 `开始检查`，点“检查上次删除的结果”。

</details>

<details>
<summary><strong>Windows 提示“无法验证发布者”，或者不让运行？</strong></summary>

这是因为脚本没有数字签名。请先确认 ZIP 是从本页面（`github.com/LongXL6/windows-360-cleaner`）下载的；不确定就不要运行。

如果是公司、学校的电脑被策略阻止，请联系电脑管理员。**不要为了运行它而关闭杀毒软件或系统安全防护。**

</details>

<details>
<summary><strong>写着“可以删除”的都应该删掉吗？</strong></summary>

不一定。“可以删除”只说明这是 360 留下、可以删掉的东西。你还在用的（例如 360 安全浏览器）就先别删；拿不准的就不勾、不说编号，没选的，本工具不会去删。

</details>

<details>
<summary><strong>会删掉我的浏览器书签吗？</strong></summary>

默认不会。浏览器的“个人资料（书签、历史等）”和“程序文件”是两个不同的项目，个人资料显示为“不删除：书签和历史记录”，在窗口里不能勾选，Agent 也不会把它算进去。删除浏览器程序文件后浏览器就打不开了，所以删除前仍建议备份需要的书签。

</details>

<details>
<summary><strong>我在 Windows 弹出的窗口里点了“否”，或者删除中途想停下？</strong></summary>

在 Windows 弹出的窗口里点“否”，就不会删除任何东西，窗口的结果页会显示“没有删除任何东西”。

删除一旦开始就不能中途停止，窗口也不能关闭，这是为了避免删到一半、说不清删了什么。检查可以随时点“停止检查”，停止不会删除任何东西。

</details>

<details>
<summary><strong>删除后显示“还差一步：请重启电脑”“有些没删掉”或“不确定有没有删干净”？</strong></summary>

有些文件正在被使用，要重启后才能删完，这很常见。保存工作后手动重启，再次双击 `开始检查`，点 `检查上次删除的结果`；用 Agent 删除的，重启后告诉 Agent “重启好了”。

不要反复强删。如果重启后检查还是有问题，点 `获取帮助`，检查过里面的文字后发给愿意帮你的人，或提交到 GitHub 求助页面。

</details>

<details>
<summary><strong>重启后打开，没有出现“上次删除的记录”，直接开始检查电脑了？</strong></summary>

说明工具没有找到能用的上次删除记录，例如桌面上的记录文件被移动或删除了，或者上次删除没有真正开始，或者上次用的是 1.0.0 之前的版本。如果上次是在 Agent 对话里删除的，窗口首页也不会显示它，请回到 Agent 那里说“帮我检查上次删除的结果”。窗口会直接重新检查一遍电脑，你一样能看到电脑上现在还有什么。

</details>

<details>
<summary><strong>记录文件保存在哪里？需要打开吗？</strong></summary>

不需要打开，窗口和 Agent 都会把内容用大白话说明。记录文件保存在桌面上（桌面不可用时保存在临时文件夹），文件名类似：

- `360-cleanup-scan-….json`：检查电脑的记录
- `360-cleanup-remove-….json`：删除的记录
- `360-cleanup-verify-….json`：检查上次删除结果的记录
- `360-cleanup-task-….json`：窗口里删除时留下的任务记录，只用来在重启后找到对应的记录、检查上次删除的结果，**不能用来删除任何东西**

在“详细信息”或“获取帮助”窗口里点 `打开记录所在文件夹` 可以直接找到它们。记录里可能有你电脑上的文件路径，不要公开发给别人；求助时请用“获取帮助”生成、并检查过的文字。

</details>

<details>
<summary><strong>一次最多只能删除 64 项？</strong></summary>

是的，这是为了安全设置的上限。先删一部分（例如一次只删一个软件），删完后重新检查电脑，再删下一批。在对话里，如果一个软件本身就超过 64 项，Agent 会请你用 `开始检查` 窗口分几次删除。

</details>

<details>
<summary><strong>360 或多绘屏保删了又回来了？</strong></summary>

可能有下载它的更新服务或定时任务还在。重新检查电脑（让 Agent 检查，或重新双击 `开始检查`），看看有没有相关的后台服务、定时自动运行的任务或 winToolBox 里的 360 程序文件。背后的原因见下文 [检测范围（技术细节）](#检测范围技术细节) 里的“为什么多绘屏保会‘删了又回来’”，处理思路见 [疑难排查](references/troubleshooting.md)。

</details>

<details>
<summary><strong>手机或 Mac 能用吗？</strong></summary>

不能。它只能在 Windows 10/11 电脑上运行。手机可以阅读说明，但要在需要检查的那台 Windows 电脑上使用。

</details>

更多图文步骤和卡点处理见 [新手图文指南](references/getting-started.md)。

## 维护者与技术说明

下面的内容写给维护者、开发者和想了解细节的用户。普通用户不需要阅读，也不需要运行任何命令。

### 高级命令行

核心脚本是 `scripts\Invoke-360Cleanup.ps1`。直接运行它不会打开窗口，只输出 JSON 报告，适合 Agent、CI 和只要报告的场景。给 Agent 用的大白话翻译器是 `scripts\Show-360Summary.ps1`：它只读取报告、打印文字，不删除任何东西、不启动任何进程、不写文件，也不上传。

<details>
<summary><strong>PowerShell 命令和高级选项</strong></summary>

```powershell
# 只读扫描（不打开窗口）
.\scripts\Invoke-360Cleanup.ps1 -Mode Scan

# 把扫描报告翻译成大白话（给 Agent 用；末尾 AGENT: 开头的行不念给用户）
.\scripts\Show-360Summary.ps1 -Report 'C:\path\to\scan-report.json'

# 用户说出编号后：打印确认内容和精确的删除命令（本身不删除；-ScanReportHash 用上一步输出的 report-sha256）
.\scripts\Show-360Summary.ps1 -Report 'C:\path\to\scan-report.json' -ScanReportHash <report-sha256> -Delete 1,2

# 删除后、复检后：必须带上刚才那条命令的退出码（拿不到时写 unknown）
.\scripts\Show-360Summary.ps1 -Report 'C:\path\to\remove-report.json' -Mode Remove -ScanReportHash <report-sha256> -ExitCode 0
.\scripts\Show-360Summary.ps1 -Report 'C:\path\to\verify-report.json' -Mode Verify -ExitCode 0

# 新的对话里找到这个 Windows 用户最近一次删除（只读）
.\scripts\Show-360Summary.ps1 -FindLastRemove

# 按整份已审阅的 Scan 报告清理：需要管理员权限（UAC）、开关和精确确认短语
.\scripts\Invoke-360Cleanup.ps1 -Mode Remove -ApprovedReport 'C:\path\to\approved-scan.json' `
  -ConfirmRemoval -ConfirmationPhrase REMOVE-CONFIRMED-360

# 重启后只读复检这次清理（对照 Remove 报告里记录的选择）
.\scripts\Invoke-360Cleanup.ps1 -Mode Verify -PreviousRemoveReport 'C:\path\to\remove-report.json'

# 不对照清理记录，只读检查整台电脑
.\scripts\Invoke-360Cleanup.ps1 -Mode Verify

# 高风险可选项：先用同一选项生成 Scan 报告，备份并单独审阅浏览器资料
.\scripts\Invoke-360Cleanup.ps1 -Mode Scan -IncludeBrowserProfiles

# 再使用上一步实际生成且已审阅的报告执行删除
.\scripts\Invoke-360Cleanup.ps1 -Mode Remove -ApprovedReport 'C:\path\to\approved-scan.json' `
  -ConfirmRemoval -ConfirmationPhrase REMOVE-CONFIRMED-360 `
  -IncludeBrowserProfiles -BrowserProfileConfirmation DELETE-360-BROWSER-DATA

# 扫描另一块磁盘上的 Windows，绝不删除
.\scripts\Invoke-360Cleanup.ps1 -Mode Scan -OfflineWindowsRoot F:\
```

- 不传选择参数时，Remove 处理“已批准报告”和“提权后重新扫描结果”中仍为 `Confirmed` 的全部交集。只想处理其中一部分时，在窗口里逐项勾选，或在对话里用 `Show-360Summary.ps1 -Delete` 按用户说出的编号生成命令；两者都会把所选 ID 和原始 Scan 报告的 SHA-256 一起绑定，不要手工构造或扩大选择列表。
- `Show-360Summary.ps1` 的退出码：`0` 已输出摘要（带 `-Delete` 时表示选择通过检查、附带删除命令）；`2` 不下结论（缺少或无效的 `-ExitCode`、`-ScanReportHash`；报告缺失或读不出来，又看不出是哪一步（没有 `-Mode`，文件名也不是 `360-cleanup-scan|remove|verify-*`）；报告类型不对；或有值没写参数名）。报告缺失但看得出是哪一步时仍是 `0`，文字不会说完成（Remove 是“不确定有没有删干净”）；`3` `-Delete` 的选择没有通过，不输出删除命令；`1` 意外错误。参数、`AGENT:` 行和 `-Json` 字段见 [SKILL.md](SKILL.md)。
- `-EmitProgress` 和 `-ElevatedProgressPath` 只用于让窗口显示当前阶段，不改变删除范围。
- `-AllowExplorerRestart` 和 `-ForceLockedTargets` 是高级故障处理选项，不在新手流程中启用。Agent 必须先解释精确目标和风险，再重新获得批准。对 `AccessDenied` 路径，`-ForceLockedTargets` 只在其他动作结束后修复已验证的精确路径 ACL，然后从已批准根路径重新扫描；一旦出现重解析点或未知检查错误就不会删除。

**Verify 退出码：**

| 场景 | `0` | `2` | `3` | `4` |
|---|---|---|---|---|
| 不带 `-PreviousRemoveReport` | 没有 `Confirmed` 且检查完整 | 仍有 `Confirmed` | 没有 `Confirmed`，但检查不完整 | — |
| 带 `-PreviousRemoveReport` | 所选目标都已清除，没有新发现，检查完整 | 所选目标仍存在或已变化；或记录不可用且仍有 `Confirmed` | 所选目标结果未知、检查不完整，或记录不可用且没有 `Confirmed` | 所选目标已清除，但出现新的 `Confirmed` |

用户主动保留的目标不会导致失败。完整规则见 [SKILL.md](SKILL.md)。

**其他入口：**

- `scripts\Scan-360.cmd`、`scripts\Verify-360.cmd`：打开同一个图形窗口，分别直接进入“检查电脑”和“检查上次删除的结果”（找到上次删除的记录时逐项检查这次删除，否则检查整台电脑），并保留一个控制台窗口。
- `scripts\Remove-360.cmd`：旧版/高级的“整份报告”命令行入口。依次按 `Y`、输入 `REMOVE-360`、拖入已审阅的 Scan JSON，再在 Windows 权限窗口确认；它处理这份报告中全部仍然确认的目标，不适合只想删其中几项的新手。

</details>

### 报告文件与统计

<p align="center">
  <img src="assets/readme/cleanup-report.svg" alt="Remove 报告 Summary 统计和默认保护内容的示意图，图中数字仅作演示" width="100%">
</p>

- 图形窗口把报告保存在桌面（不可用时保存在临时文件夹），文件名为 `360-cleanup-scan-*.json`、`360-cleanup-remove-*.json`、`360-cleanup-verify-*.json`，另有 `360-cleanup-task-*.json` 任务记录和用户在“获取帮助”里手动保存的 `360-cleanup-help-*.txt` 问题信息。直接运行核心脚本且不传 `-ReportPath` 时，默认文件名是 `360-cleanup-report-*.json`；`Show-360Summary.ps1` 打印的命令会带上 `360-cleanup-remove-*.json`、`360-cleanup-verify-*.json` 这样的新路径。
- 报告只会新建，拒绝覆盖已有文件或使用其他扩展名。
- 报告仍是 `SchemaVersion 2`。1.0.0 新增的 `ToolVersion`、`ScanCoverage`、每个发现项的 `ProductKey`、Remove 报告的 `Selection`、Verify 报告的 `TaskVerification` 都是可选字段；旧报告仍然可以读取。旧版本生成的 Remove 报告没有记录选择，逐项检查上次删除的结果会显示为不可用（`SelectionNotRecorded`），但不带 `-PreviousRemoveReport` 的 Verify（检查整台电脑）照常可用。
- `ProductKey` 和 `Show-360Summary.ps1` 的编号只用于分组显示，不会扩大或缩小批准范围。

Remove 报告中的 `Summary` 会记录：

- 删除的总对象、文件、目录和文件逻辑大小。
- 已删除和仍待 Windows 重启后删除的服务数。
- 删除的计划任务、注册表键和注册表值数量。
- 停止的目标进程，以及跳过、失败、待处理、重试和最终未解决的数量。
- 拒绝访问的路径、ACL 修复尝试/失败数，以及仍未解决的路径数。
- 厂商卸载器的成功、失败和待定数，以及厂商卸载器运行后的安全复查是否阻断了后续操作。
- 获批数量、当前仍可处理的交集，以及批准后新增、消失或不再确认的数量。
- 本次勾选、明确保留未勾选、即时复查确认已清除、仍存在或无法确认的所选目标数量。
- 完全删除、部分清理和无法安全测量的路径数量。

文件大小来自删除前后的安全快照差值，并对父子目标去重。硬链接、稀疏文件和压缩文件可能让“文件逻辑大小”与“磁盘实际新增可用空间”不同，所以本项目不会把两者混为一谈。如果 `ImmediateRescanComplete` 为 false，报告中的 Findings 只是最后一份安全的操作前快照，不是剩余状态证明，本次结果必须标记为需要人工关注。重启后的最终结果以 Verify 报告的 `TaskVerification` 和 `Findings` 为准。Agent 默认用几句大白话报告结果（见 [SKILL.md](SKILL.md) 的 Required final output）；用户要详细信息时需要报告的完整字段见其中的 Details on request。

### 安全设计细节

| 防呆保护 | 实际行为 |
|---|---|
| 先扫描后删除 | `Scan` 只读；`Remove` 需要未修改的 Scan 报告、开关、精确确认短语和 Windows 管理员权限（UAC） |
| 不替用户选择 | 窗口打开时一个都不勾选；Agent 可以给“建议删除 / 不删除”的建议，但只使用用户说出的编号。只有在线、可删除的 `Confirmed` 项目可以被选中，未选中的都会保留 |
| “全选可以删除的”只少选、不多选 | 点软件行、点“全选可以删除的”和 `Show-360Summary.ps1 -Delete` 都用同一个库函数：只取可以删除的项目，删掉会连带要保留内容的文件夹、缺少安装目录的厂商卸载程序会被去掉，永远不会加入候选以外的项目，也不会自动截断到 64 项。对整份检查结果先算一次“最多能安全一起删的项目”，在这之外、怎么选都过不了检查的项目直接显示“不删除：原因”，不能勾选，也不算进“可以删除”；这一层只会少给、不会多给，核心的批准检查不变 |
| 删除前必须确认 | 窗口的确认框默认按钮是“取消”；对话里 Agent 必须先展示同一份确认文字，等用户明确回复“确定删除”，再原样运行打印出的命令 |
| 提权后再核对 | 所选 ID 与原始 Scan 报告 SHA-256 绑定；提权后重新扫描，所选目标变化、消失、降级，或所选上级目录会连带删除未选中/不删除的内容时，在删除前停止 |
| 单次上限 | 窗口和 `Show-360Summary.ps1 -Delete` 一次最多提交 64 项 |
| 证据不足不强删 | 可疑目标进入 `ReviewOnly`（界面显示“不删除：原因”），不会自动升级为可删除项 |
| 拒绝宽泛路径 | 磁盘根目录、Windows、用户目录、整个 Temp 等路径永远不会成为删除目标 |
| 防止目录逃逸 | 目标、父路径或子树出现 junction/符号链接时失败关闭 |
| 拒绝访问不冒充成功 | 默认只跳过无法完整检查的精确路径，继续其他已批准目标，并将结果标记为需要处理 |
| 浏览器资料单独保护 | 书签、历史记录和会话默认保留；窗口里不能勾选，`Show-360Summary.ps1 -Delete` 默认不算进去，命令行删除需要单独的开关和确认短语 |
| 厂商卸载器受限 | 只运行签名、哈希、路径和产品证据都再次核对通过的多绘屏保卸载程序，并只使用内置参数；确认文字会说明它可能删掉同一产品里没选的部分 |
| 不乱杀正常软件 | 普通应用仅仅加载了目标 DLL 时不会被强停，默认要求重启后复查 |
| 不跨系统乱删 | 其他磁盘上的离线 Windows 永远只有扫描模式 |
| 复检永远只读 | 上次的 Remove 报告、任务记录和求助文字只用于对照，不能当作删除批准 |
| 结果不冒充成功 | 没删掉、不确定、需要重启永远不显示成成功；`Show-360Summary.ps1` 没有退出码时拒绝下结论，缺少 Remove 报告时说“不确定有没有删干净”，不会说“没有删除任何东西” |
| 报告不覆盖文件 | JSON 只能新建，拒绝覆盖已有报告或伪装成其他扩展名；同一条删除命令重复运行会在改动前停下 |
| 省略独立身份字段 | 默认不填 `ComputerName` / `User`；路径和批准上下文仍可能包含个人信息 |

### 检测范围（技术细节）

- 360 安全卫士、杀毒、浏览器、极速浏览器、软件管家等安装目录和卸载记录。
- `dhpingbao`、`duohuipingbao`、`huabao_tmp`、`360hb_tmp` 等画报/屏保组件。
- `SoftMgrUpdate*` 计划任务和有证据支持的第三方工具箱下载链。
- 指向已确认目标的启动项、服务和正在运行的进程。
- Explorer 加载的 `qcnethelp64.dll`、`xhqcnethelp64.dll`、`SoftMgrExt64.dll` 等锁定模块。
- 用户指定的其他 Windows 磁盘；这些结果始终只报告、不跨系统删除。
- `360se6\User Data`、`360Chrome\Chrome\User Data`、`360ChromeX\Chrome\User Data` 和旧版 `360browser` 中的浏览器个人资料默认保留；程序目录会单独检测。

判断依据和已知误报见 [检测目录](references/detection-catalog.md)。

<details>
<summary><strong>WinToolBox 是谁家的，为什么会与 360 组件一起出现</strong></summary>

`WinToolBox` 不是微软或 Windows 官方软件，也不是 360 官方产品。我们在真实机器上确认其主程序、看图、清理和 PDF 组件由 **北京奥蓝德信息科技有限公司**签名；服务名带有 `huajun`，与华军软件园体系相符。

同一个工具箱目录可能混入由**北京奇虎科技有限公司**签名的 `KitTip.dll`、`cssdk.dll`，后者产品信息为 `360.cn / 统计组件`。我们还遇到过其 `SoftMgr` 子目录包含 360 安全卫士组件并参与下载多绘屏保。

因此本项目将它描述为：**奥蓝德/华军系第三方工具箱；当本机存在奇虎签名 DLL、360 SoftMgr、自动下载任务或多绘屏保链路时，按 PUP/捆绑推广载体处理，而不是误称为 360 官方 WinToolBox。** 窗口和 Agent 里整个工具箱显示为“不删除：这是别的软件”，只有其中单独识别出的 360 部分显示为“可以删除”。

数字签名只能证明发布者身份，不代表软件行为一定符合用户意愿。公开入口：[奥蓝德](https://www.softbutler.cn/) · [华军软件园](https://www.onlinedown.net/contact.html)

</details>

<details>
<summary><strong>为什么多绘屏保会“删了又回来”</strong></summary>

我们遇到过的真实链路是：

```text
奥蓝德/华军系 winToolBox 更新服务
  → 含 360 组件的 SoftMgrUpdate* 计划任务
  → Temp\duohuipingbao\360hb_tmp\huabaosetup.exe
  → AppData\Local\dhpingbao\duohuipingbao.exe
  → Explorer 加载 qcnethelp / SoftMgrExt DLL
```

如果只删除最终屏保目录，不删除有证据支持的下载服务和更新任务，它就可能重新出现。本技能会先找下载来源，再处理持久化，最后验证；普通软件仅仅加载了目标 DLL 时不会被强停。

如果已确认的 `%LOCALAPPDATA%\dhpingbao` 包含符合证据的 `huabaosetup.exe`，Scan 会把它的精确路径和 SHA-256 单独列入批准清单（窗口中显示为“多绘屏保自带的卸载程序”）。因为这是用户可写目录中的可执行文件，它还必须具有有效 Authenticode 签名，且签名者简称精确为 `Beijing Qihu Technology Co., Ltd.`；其他情况只会标记为 `ReviewOnly`。Remove 会在启动前再次验证签名、哈希和路径，并且只使用内置的 `/uninstall:byUserName` 参数，不会盲目执行注册表中的命令行。服务、任务和注册表对象的稳定身份指纹也是 Scan 批准身份的一部分；任何同名替换或之后的内容变化都会被跳过，并要求重新扫描批准。

</details>

### 打包版本 ZIP

维护者运行 `tools\Build-Release.ps1`，会在 `dist\` 生成 `windows-360-cleaner-v<版本>.zip` 和对应的 `.sha256` 校验文件。脚本会先检查 `VERSION`、核心脚本、界面库和 `CHANGELOG.md` 的版本号是否一致；它只在输出目录生成这两个文件，**不会发布、上传、打标签或提交**。

ZIP 里有一个 `windows-360-cleaner-v<版本>` 文件夹，包含两个“开始检查”入口、`使用说明.txt`（由 `packaging\使用说明.txt` 模板生成）、README、`SKILL.md`、`CHANGELOG.md`、`VERSION`、`LICENSE`、`agents`、`scripts`（含 `Show-360Summary.ps1`）、`tests`、`references`、`assets\readme` 和 `assets\screenshots`，不包含 `.github`、`docs`、`tools`、`packaging` 和扫描报告。

更新版本号、运行测试、检查 ZIP、手动创建 GitHub Release 的完整步骤，见 [发布与维护指南](references/publishing.md) 中的“发布版本 ZIP”一节。
